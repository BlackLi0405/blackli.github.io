工具・裝到手機

把黑板放進口袋

不用下載、不用註冊。加到手機主畫面後，點圖示就像打開 App 一樣，全螢幕閱讀，讀過的文章沒網路也看得到。

你現在就是從主畫面打開的，已經裝好了。每天 07:45 早報、16:30 盤後、21:00 盤前，打開就是最新內容。
你的手機
🍎

iPhone・iPad

  1. 用 Safari 打開這個網站
  2. 點下方的 分享 按鈕（方框加向上箭頭）
  3. 往下滑，點 加入主畫面
  4. 右上角點 新增

從 IG 連結打開的話，先點右上角「⋯」選「在外部瀏覽器開啟」，再照上面做。

你的手機
🤖

Android

  1. 用 Chrome 打開這個網站
  2. 點右上角 ⋮ 選單
  3. 點 安裝應用程式 或 加到主畫面
  4. 點 安裝
你的電腦
💻

電腦

  1. 用 Chrome 或 Edge 打開這個網站
  2. 網址列右邊會出現 安裝 圖示，點它
  3. 之後可以從桌面或開始選單直接打開
